# SuDeMa Stage Workflow — bộ cài

Trang này chỉ chứa **bộ cài** và tệp cập nhật của SuDeMa Stage Workflow (app LED Mapper + plugin SketchUp).

- Tải bản mới nhất: mục **Releases** → `SuDeMa-Stage-Setup-<phiên bản>.exe`
- App tự kiểm tra bản mới qua `latest.json` (có chữ ký số, chỉ cài bộ cài do HTTP phát hành).
- Cần mã kích hoạt: liên hệ HTTP.
